# Career Intelligence System

AI-powered career intelligence and positioning platform designed to help professionals improve:

- opportunity targeting
- sponsorship-aware job matching
- strategic outreach
- resume tailoring
- interview conversion rates

## Core Features

- ATS-aware job extraction
- semantic skill matching
- sponsorship intelligence
- structured job intelligence pipelines
- AI-assisted resume tailoring
- relationship intelligence
- lightweight local-first architecture

## Technology Stack

- Python 3.12
- Streamlit
- SQLite
- Playwright
- ScrapeGraphAI
- Ollama
- Sentence Transformers
- SQLAlchemy
- Pydantic

## Design Principles

- lightweight architecture
- modular execution
- human-in-the-loop AI
- low resource usage
- local-first workflows
- maintainable engineering
